
# 📘 Atividade: Jogos em Python

## 🎯 Objetivo

Construa o clássico jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Preparar a palavra e exibir o progresso

#### Descrição
Implemente a seleção aleatória de uma palavra e permita que o jogador tente descobri-la informando uma letra por vez. Após cada palpite, exiba as letras corretas e os espaços ainda ocultos.

#### Requisitos
O programa concluído deve:

- Escolher aleatoriamente uma palavra de uma lista predefinida.
- Solicitar palpites de letras ao jogador.
- Exibir cada letra descoberta na posição correspondente e representar as letras ainda não descobertas por espaços, por exemplo, `_ _ _`.

### 🛠️ Controlar as tentativas e encerrar a partida

#### Descrição
Controle os palpites incorretos e encerre o jogo quando o jogador adivinhar a palavra ou esgotar as tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Definir e exibir a quantidade de tentativas incorretas restantes.
- Reduzir as tentativas restantes quando o jogador informar uma letra que não está na palavra.
- Encerrar a partida quando a palavra for adivinhada ou quando não houver mais tentativas.
- Informar claramente se o jogador venceu ou perdeu.
